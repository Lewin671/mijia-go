# Security policy

The latest preview release is the supported version. The software is experimental; see [security boundaries](docs/security.md) before using real credentials.

Please use GitHub's **Report a vulnerability** action in this repository's Security tab for credential exposure, authorization bypasses, unsafe destinations, or code-execution issues. If private reporting is unavailable, open a public issue requesting a private contact channel **without disclosing exploit details or private data**.

Never upload `auth.json`, QR codes, cookies, API tokens, raw authentication responses, production HAR files, or unredacted logs. A minimal synthetic reproduction is enough to start an investigation.

We will acknowledge reports as capacity permits. There is no promised response SLA or bug bounty.
